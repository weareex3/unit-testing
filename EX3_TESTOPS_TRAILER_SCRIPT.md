# EX3 TestOps Trailer Script

## Goal

Create one polished product trailer that shows the real workflow of EX3 TestOps:

`Upload -> match -> run -> intervene only when needed -> approve -> save -> replay forever`

This is a product walkthrough trailer, not a hype reel. The viewer should understand:

1. What the platform does
2. How the workflow works
3. Why it gets more valuable every time it is used

## Deliverables

Use this script to create:

1. `55s` master trailer
2. `30s` cutdown
3. `15s` teaser

## Visual Direction

- Premium enterprise product launch
- Calm cursor movement
- No frantic scrolling
- One browser size throughout
- Pause briefly before and after every key action
- Keep each shot clean enough to use with or without voiceover

## Capture Settings

- Format: `16:9`
- Resolution: `1920x1080`
- Browser zoom: `100%`
- Use the same browser window size for all shots
- Record each shot separately
- Leave `1 second` of stillness at the start and end of every clip

## Core Message

`Teach it once. Replay it forever.`

## Master Trailer

### Duration

`55 seconds`

### Voiceover

User acceptance testing in SuccessFactors usually means repetition. The same scripts. The same steps. The same manual effort, over and over again.

EX3 TestOps changes that.

Upload a UAT workbook, and every scenario is parsed automatically. Before a run even starts, TestOps checks what it already knows, what partially matches, and what still needs attention.

Known tasks replay exactly as approved. New tasks are attempted live by AI inside the real SuccessFactors interface.

When something needs judgment, you step in. Guide the task once, confirm the result, and save it back to the library.

From that point on, the workflow is remembered. Future scripts are matched by intent, not wording. What was new becomes reusable. What was manual becomes automatic.

Every run leaves proof behind: recorded video, step evidence, and a full audit trail ready for sign-off.

Upload. Teach once. Replay forever.

EX3 TestOps. SuccessFactors UAT that learns.

## Exact Interaction Script

### Sequence A - Ingestion

1. Open login page
2. Sign in
3. Land inside the product
4. Go to upload
5. Upload one workbook
6. Choose module
7. Submit upload
8. Open the script from the Vault

### Sequence B - Memory

1. Show the scenario list
2. Trigger `Match with tasks`
3. Wait for the matched results to appear
4. Pause long enough to read green states

### Sequence C - Run All

1. Open `Run All`
2. Pause on the command centre
3. Fill any required variable once
4. Click `Start full run`
5. Capture the first known task completing

### Sequence D - Unknown Task

1. Move to a task that is not fully learned
2. Show the agent attempt or paused state
3. Open live training
4. Perform one or two clean human correction actions
5. Complete the step

### Sequence E - Approval and Memory

1. Open the run video
2. Pause on the proof view
3. Click `Approve video + save task`
4. Confirm the save prompt
5. Return to the list or board
6. Show the greener / matched state

### Sequence F - Trust Close

1. Open run history or audit
2. Show evidence artifacts
3. End on the strongest overall product screen
